# 刷机说明

源码在 `esp32-dashboard/`，用 PlatformIO 编译。压缩包里没有 WiFi 密码和打印机访问码。

## 1. 填写配置

把 `include/secrets.example.h` 复制成 `include/secrets.h`，填这几项：

| 宏 | 填什么 |
|---|---|
| WIFI_SSID / WIFI_PASSWORD | 2.4G WiFi。ESP32 连不上 5G |
| BAMBU_IP | 第一台打印机的 IP |
| BAMBU_SERIAL | 序列号。不知道就在电脑上运行 `openssl s_client -connect <IP>:8883`，看证书 CN |
| BAMBU_ACCESS_CODE | 打印机屏幕或 App 设备信息里的访问码 |
| BAMBU2_* | 第二台，没有就先留着，界面会显示离线 |
| CURSOR_SESSION_TOKEN | 可选。浏览器登录 cursor.com，从 Cookie 里复制 WorkosCursorSessionToken |

打印机不用打开「仅局域网」。打开之后手机 App 会找不到设备，访问码在普通联网状态下也能用。

城市在 `include/config.h` 的 `WEATHER_CITY`、`WEATHER_LAT`、`WEATHER_LON`。打印机在界面上的名字是 `PRINTER_NAME` 和 `PRINTER2_NAME`。

## 2. 编译并上传

安装 [PlatformIO](https://platformio.org/) 后，用它打开 `esp32-dashboard` 目录，连接开发板的 USB，上传。

板子是 ESP32-S3-N16R8。`platformio.ini` 里已经选了 `esp32-s3-devkitc-1`、16MB Flash 和 OPI PSRAM。

## 3. 上传之后

开发板重启。连上 WiFi 后，浏览器打开它的 IP，或者 `http://esp32dash.local/`，能看到和屏幕一样的界面。

画面上下颠倒时，把 `include/config.h` 里的 `LCD_ROTATION` 从 `1` 改成 `3`，重新上传。红蓝反了就把 `LCD_RGB_ORDER` 改成 `true`。

电阻屏要用手指按实。30 秒没有触摸，页面会自动切到下一页。
